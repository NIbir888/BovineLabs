# Grruzam DualBlade Animation

Unity UPM package for **Grruzam DualBlade Animation**.

## Contents

This package preserves the original Unity assets and `.meta` files from:

`Assets/Art/Third Party/Grruzam_DualBlade_Animation`

It may include FBX animations, animator controllers, prefabs, materials, meshes, preview/demo scenes, documentation, and related assets depending on the original pack contents.

## Requirements

- Unity 6000.0 or newer recommended
- No custom runtime scripts required

## Install from GitHub

Unity Package Manager → `+` → **Add package from git URL...**

```text
https://github.com/SadmanShafin/grruzam-dualblade-animation-unity-package.git
```

Or pin the release tag:

```text
https://github.com/SadmanShafin/grruzam-dualblade-animation-unity-package.git#v1.0.0
```

## Usage

After import, open **Packages/Grruzam DualBlade Animation** and use the included assets in your project.
