# Dual Sword Animation Pack

Unity UPM package for **Dual Sword Animation Pack**.

## Install

Unity Package Manager → `+` → **Add package from git URL...**

```text
https://github.com/SadmanShafin/dual-sword-animation-pack-unity-package.git#v1.0.0
```

## Contents

Original DualSwordAnimationPack assets with Unity `.meta` files preserved.
