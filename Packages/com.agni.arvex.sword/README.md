# Arvex Sword

Unity UPM package for the Arvex sword assets.

## Contents

- `Sword/SM_Sword.fbx`
- `Sword/Sword_L.fbx`
- `Sword/Sword_R.fbx`
- `Sword/M_Sword.mat`
- `Sword/Texture/T_Diffuse.png`
- `Sword/Texture/T_Emissive.png`
- `Sword/Texture/T_Normal.png`

## Requirements

- Unity 6000.0 or newer
- Universal Render Pipeline `17.6.0` or compatible

## Install from GitHub

Unity Package Manager → `+` → **Add package from git URL...**

```text
https://github.com/SadmanShafin/arvex-sword-unity-package.git
```

Or pin a release tag:

```text
https://github.com/SadmanShafin/arvex-sword-unity-package.git#v1.0.0
```

## Usage

After import, open **Packages/Arvex Sword/Sword** and drag the FBX/model or material into your scene/prefab.
