# Player XX Template

Unity Package Manager package containing the reusable `Player_XX` prefab.

## Install

In Unity, open **Package Manager > Add package from git URL...** and paste:

```text
https://github.com/Efarjeon/player-xx-template.git
```

## Contents

- `Prefabs/Player_XX.prefab`
- `Settings/Schemas/EntityLinks/Root Link.asset`
- `Settings/Schemas/EntityLinks/Essence Link.asset`

## Notes

This package depends on Unity Entities/Physics/URP and the BovineLabs Timeline packages used by the prefab authoring components.
